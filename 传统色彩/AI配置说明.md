## AI配置步骤

### 1. 获取百度千帆API密钥

1. 访问 [百度千帆大模型平台](https://cloud.baidu.com/product/wenxinworkshop)
2. 注册/登录百度账号
3. 进入控制台，创建应用
4. 获取 `API Key` 和 `Secret Key`

### 2. 配置AI密钥

打开 `ai-chat.js` 文件，找到以下配置：

```javascript
var AI_CONFIG = {
  API_KEY: 'YOUR_API_KEY',        // 替换为您的API Key
  SECRET_KEY: 'YOUR_SECRET_KEY',    // 替换为您的Secret Key
  API_URL: 'https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop/chat/completions',
  MODEL: 'ERNIE-Bot-4.0'
};
```

将 `YOUR_API_KEY` 和 `YOUR_SECRET_KEY` 替换为您实际的密钥。

### 3. 选择AI模型

百度千帆提供多种模型，您可以根据需求选择：

- `ERNIE-Bot-4.0` - 最强模型，适合复杂问题
- `ERNIE-Bot-3.5` - 性价比高，适合一般对话
- `ERNIE-Speed` - 响应快速，适合简单问答
- `ERNIE-Lite` - 免费模型，适合基础功能

修改 `MODEL` 参数即可切换模型。

## 故障排除

### 问题1：AI无法响应

**可能原因**：
- API密钥配置错误
- 网络连接问题
- API余额不足

**解决方法**：
1. 检查 `ai-chat.js` 中的密钥配置
2. 检查网络连接
3. 登录百度云控制台查看余额

### 问题2：响应速度慢

**可能原因**：
- 使用了高级模型
- 网络延迟
- 服务器负载高

**解决方法**：
1. 切换到更快的模型（如ERNIE-Speed）
2. 检查网络连接
3. 稍后再试

### 问题3：回答质量不佳

**可能原因**：
- 问题表述不清晰
- 模型选择不当

**解决方法**：
1. 优化问题表述，更加具体明确
2. 尝试使用更高级的模型（如ERNIE-Bot-4.0）

## 安全建议

1. **保护密钥**：不要将API密钥提交到公共代码仓库
2. **限制访问**：在生产环境中，建议通过后端代理API请求
3. **监控使用**：定期检查API使用量和费用
4. **设置限额**：在百度云控制台设置调用限额，避免意外超支
