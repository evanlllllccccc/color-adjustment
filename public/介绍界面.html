🎨 传统色彩数字工坊

探寻东方色彩之美 · 数字化传承与创新平台

传统色彩数字工坊是一个集色彩文化展示、在线染色创作、用户社交互动与数据管理于一体的综合性平台。我们收录了数百种中国传统色，结合现代 Web 技术，让用户能够在线体验「区域染色」的乐趣，同时为管理员提供全方位的后台管理工具。

📌 平台核心特色

🎴 传统色基因库

内置红、橙、黄、绿、青、蓝、紫、白、黑、褐十大色系，每个颜色均标注名称与十六进制色值，并支持个人调色盘保存自定义颜色。

🖌️ 智能区域染色

基于 Canvas 的泛洪填充算法，点击画布封闭区域即可一键上色。支持色相、饱和度、亮度、透明度及容差实时调节，还原真实染色体验。

☁️ 云端数据同步

所有用户作品、草稿、素材、评论点赞及私信均通过后端 API 持久化存储。登录后数据自动同步，更换设备也能继续创作。

🤖 AI 辅助功能

管理员端集成 AI 标签推荐，可对上传素材自动生成分类标签；未来还将扩展 AI 色彩搭配建议与作品评分系统。

🧑‍🎨 游客与用户功能

游客模式 无需注册，即刻浏览

  • 查看热门染色作品（按点赞数排序），欣赏优秀创作。
  • 访问作品库、排行榜、项目介绍，了解平台全貌。
  • 体验染色工坊基础功能（部分高级功能需登录）。

注册用户 解锁完整创作工具

  • 个人中心：管理头像、简介，查看作品/草稿/获赞/评论/私信，统计数据（作品数、总点赞、浏览量）一目了然。
  • 染色工坊：上传本地图片或使用管理员预设素材，自由染色后支持导出 PNG、保存至云端作品库或存为草稿继续编辑。
  • 作品库：发布公开作品，其他用户可点赞、评论，并可通过私信交流创作心得。
  • 排行榜：综合点赞与浏览量生成热度排名，激励创作者持续产出优质内容。
  • 私信系统：与任何用户一对一聊天，收到评论或点赞时可快速回复，未读消息有红点提示。

🛠️ 管理员后台系统

平台为管理员提供独立的后台界面，需通过管理员账号登录。主要模块包括：

  • 数据统计看板：实时展示用户总数、今日新增、浏览量、染色次数、作品总量等核心运营指标，支持一键刷新。
  • 用户作品库管理：查看所有用户发布的作品，支持按热度/时间排序、关键词搜索，并可删除违规作品。
  • 评论监管：集中查看全站评论，对不当言论进行删除处理，维护社区氛围。
  • 素材管理：上传公共染色底图（预设素材），设置名称与分类，用户即可在染色工坊中选用。支持 AI 辅助生成分类标签。
  • 热度排行：多维度展示作品热度，便于分析内容趋势。

🌈 技术实现亮点

  • 前端：原生 HTML/CSS/JavaScript，响应式布局，适配 PC 与移动端；Canvas 实现图像处理与泛洪填充算法。
  • 后端对接：所有数据接口统一使用 RESTful API，通过 Bearer Token 进行身份验证，确保数据安全。
  • 数据持久化：用户作品、草稿、素材、评论、点赞、私信等全部存储于云端数据库，替代传统 localStorage 方案，实现真正的多端同步。
  • 用户体验：模拟传统染色工坊的交互流程，提供撤销、重命名、导出等实用工具，降低创作门槛。

📖 文化传承意义

中国传统色彩是东方美学的重要载体，每一种颜色背后都蕴藏着诗词典故与工艺智慧。本项目通过数字化手段，将“胭脂”“黛蓝”“秋香”等雅致色名与具体色值关联，让用户在创作中感受色彩背后的文化温度。无论是专业设计师寻找配色灵感，还是普通爱好者体验传统染色工艺，都能在这里找到属于自己的东方色彩。
